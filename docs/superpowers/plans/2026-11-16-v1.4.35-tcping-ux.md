# KoNeko v1.4.35 TCPing Display Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Make TCPing/ICMPing show skipped nodes (TUIC/Hysteria/WireGuard/OpenVPN/OpenConnect/custom JSON configs) in the test dialog and count them in the progress total, and show a toast instead of flashing an empty dialog when a group has no testable nodes — without changing which nodes get tested.

**Architecture:** Split the group into testable/skipped with `partition` inside `pingTest`, count `proxyN` as the total, render skipped nodes through a new `TestDialog.showSkipped()` that only touches dialog UI (never `test.results` or profile state), and move the dialog `show()` behind the empty check inside `mainJob`. New strings in all three locales.

**Tech Stack:** Kotlin, Android Fragment + coroutines (`runOnLifecycleDispatcher` = `lifecycleScope.launch(Dispatchers.Default)`, `onMainDispatcher` = `withContext(Dispatchers.Main.immediate)`), file-parsing unit tests in `app/src/test/java/io/nekohasekai/sagernet/ui/`.

**Spec:** Parent task brief (v1.4.35): fix the TCPing display problem only; do not change the `canTCPing()`/`canICMPing()` filter itself; TUIC/Hysteria/custom configs still do not participate in TCPing; `urlTest` untouched.

## Global Constraints

- Version: `nb4a.properties` → `VERSION_NAME=1.4.35`, `VERSION_CODE=79` (versionCode=395), `PRE_VERSION_NAME=pre-1.4.34`.
- Release signing fingerprint must stay `124d11a298e17d26b812235d068e1c6531d08062716b7a096805426f33bb819e`.
- Canonical tree is the VM `/data/workspace/koneko/nekobox-tmp` only; do not touch the sandbox copy; do not push GitHub; do not copy the keystore anywhere.
- `urlTest` filtering/behavior untouched: it tests every protocol, it does not use `canTCPing()`/`canICMPing()`.
- Skipped nodes must never enter `test.results` and their `ProxyEntity` objects must never be mutated, or `test.cancel` would persist fake status via `ProfileManager.updateProfile`.
- `runOnLifecycleDispatcher` runs on `Dispatchers.Default`, not Main: all dialog/snackbar/binding touches inside `mainJob` must go through `onMainDispatcher { }` (suspend) or `runOnMainDispatcher { }` (fire-and-forget).
- New strings go in `app/src/main/res/values/strings.xml`, `values-zh-rCN/strings.xml`, `values-ru/strings.xml`.
- Tests are file-parsing style (same as `Fixes1434Test`): tests run with working directory `app/`, so production sources are read via `src/main/...` and `nb4a.properties` via `../nb4a.properties`.

## Review Focus

- Skipped node rendered but its `ProxyEntity.status`/`ping`/`error` never written, and it never lands in `test.results` — otherwise the next list reload shows a fake status that was never measured. (Covered by Task 3 test `skipped profiles are never persisted`.)
- Empty group: `DataStore.runningTest` must be reset to `false` on the early-return path, or every later test tap silently no-ops. (Covered by Task 4 test `empty group toasts instead of showing dialog`.)
- Dialog shown from `mainJob` (Default dispatcher) without a Main switch would crash with "CalledFromWrongThreadException". (Covered by Task 4 test asserting `onMainDispatcher` wraps `test.builder.show()`.)
- `test.cancel` runs via `invokeOnCompletion` even when the dialog was never shown (empty group) — the dismiss path must tolerate a null dialog. (Covered by Task 4: `dialog` is nullable, cancel uses `dialog?.let`.)
- A group with many skipped nodes must not grow the dialog without bound — `nowTesting` gets a max height + scrollbars. (Covered by Task 3 test asserting the layout markers.)

- Produces: `TestDialog.showSkipped(profile: ProxyEntity, unsupportedLabel: String)` and `TestDialog.skippedText: SpannableStringBuilder` (both used by Task 4).

Design (pinned):
- Add field `val skippedText = SpannableStringBuilder()` to `TestDialog`.
- Add `fun showSkipped(profile: ProxyEntity, unsupportedLabel: String)`: mirrors `update()` — wraps its body in `runOnMainDispatcher { }`, increments `finishedN` via `finishedN.addAndGet(1)`, updates the notification via `notification?.updateNotification(progress, proxyN, progress >= proxyN || status == 2)`, returns early when `status >= 1` or `!isAdded` (same guards as `update()`), then appends one grey line to `skippedText` (name + type in protocol color + `unsupportedLabel` in `textColorSecondary`, same `SpannableStringBuilder` shape as `update()`), sets `binding.nowTesting.text = skippedText`, sets `binding.progress.text = "$progress / $proxyN"`. It must NOT touch `results`, `profile.status`, `profile.ping`, or `profile.error`.
- Change `update()`'s final assignment from `binding.nowTesting.text = text` to `binding.nowTesting.text = SpannableStringBuilder(skippedText).append(text)` so skipped lines stay visible above the latest result. For `urlTest`, `skippedText` is always empty, so its rendering is byte-identical to today.
- Layout: `nowTesting` gains `android:maxHeight="320dp"` and `android:scrollbars="vertical"`; `TestDialog` init sets `binding.nowTesting.movementMethod = ScrollingMovementMethod()` (import `android.text.method.ScrollingMovementMethod`).

Design (pinned, `pingTest` only — `urlTest` untouched):
- In the `pingTest` body (main thread), before `mainJob`, resolve labels: `val unsupportedLabel = getString(if (icmpPing) R.string.connection_test_icmp_ping_unsupported else R.string.connection_test_tcp_ping_unsupported)`, `val noTestableToast = getString(if (icmpPing) R.string.connection_test_no_testable_nodes_icmp else R.string.connection_test_no_testable_nodes_tcp)`, `val emptyGroupToast = getString(R.string.connection_test_empty_group)`.
- Change `dialog` to a nullable var: `var dialog: AlertDialog? = null` (import already exists from v1.4.34). Do NOT show the dialog in the body.
- Inside `mainJob`, replace the `filter` with:
```kotlin
val allProfiles = SagerDatabase.proxyDao.getByGroup(group.id)
val (testableProfiles, skippedProfiles) = allProfiles.partition {
    if (icmpPing) it.requireBean().canICMPing() else it.requireBean().canTCPing()
}
```
- Empty check immediately after the split, still inside `mainJob`:
```kotlin
if (testableProfiles.isEmpty()) {
    onMainDispatcher {
        if (isAdded) snackbar(if (skippedProfiles.isNotEmpty()) noTestableToast else emptyGroupToast).show()
    }
    DataStore.runningTest = false
    return@runOnLifecycleDispatcher
}
```
- Show the dialog after the check, on Main (mainJob runs on `Dispatchers.Default`):
```kotlin
onMainDispatcher {
    dialog = test.builder.show()
    activeTestDialog = dialog
}
```
- Then `test.proxyN = testableProfiles.size + skippedProfiles.size`, then `skippedProfiles.forEach { test.showSkipped(it, unsupportedLabel) }`, then `val profiles = ConcurrentLinkedQueue(testableProfiles)`; workers and the rest unchanged.
- `test.cancel`: dismiss via `dialog?.let { dialog -> try { if (dialog.isShowing) dialog.dismiss() } catch (e: IllegalArgumentException) { Logs.w(e) } }` — the inner literal `if (dialog.isShowing) dialog.dismiss()` must stay verbatim so the v1.4.34 `test cancel dismiss is guarded` test keeps passing. `test.minimize`: wrap its body in `dialog?.let { dialog -> ... }` (dialog is non-null whenever the button exists, the guard is for the null case only).
