# v1.4.39：屏蔽模式重载提示与代理/绕过同步

## 背景
- v1.4.37 新增的屏蔽模式写 individualBlock / appBlock 两个 key，
  MainActivity.onPreferenceDataStoreChanged 只监听
  PROXY_APPS / BYPASS_MODE / INDIVIDUAL 三个 key，
  所以屏蔽模式改名单、切模式都不弹「重载代理服务以应用修改」提示。
- 2026-11-17 用户确认：点的就是「关闭」模式 Chip（写 proxyApps=false，
  属被监听 key）才弹提示；决定三者用同一套逻辑。

## 改动
1. MainActivity.kt 的 onPreferenceDataStoreChanged：when 分支补
   Key.APP_BLOCK、Key.INDIVIDUAL_BLOCK，与代理/绕过完全一致
   （每改一次弹一次、新的顶掉旧的、仅服务运行时弹）。
2. 版本号：1.4.38 (82) -> 1.4.39 (83)，PRE_VERSION_NAME=pre-1.4.38。
3. 单测 Fixes1439Test：断言监听分支包含 APP_BLOCK 与 INDIVIDUAL_BLOCK，
   且 snackbar + 应用按钮 + reloadService 接线完好。
