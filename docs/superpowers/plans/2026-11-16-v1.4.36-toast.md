# v1.4.36 Empty-Group Toast Copy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the empty-group TCPing/ICMPing toast copy with a unified message that names no specific protocols, and ship as v1.4.36.

**Architecture:** Copy-only change — two string resources × three locales, a version bump, and test updates. No logic changes; `pingTest` still partitions by `canTCPing()` / `canICMPing()` and still toasts when the testable list is empty.

**Tech Stack:** Android strings.xml (values / values-zh-rCN / values-ru), Kotlin unit tests (file-parsing style), Gradle.

**Spec:** Parent task (user decision 2026-11-16): do not list specific protocols; use one unified message. Chinese final copy is the user's verbatim wording.
