# v1.4.41：分应用开关与入口分离、Chip 改小加滚动、设置名加单位

## 第 1 项：开关与入口分开（设置页「分应用代理」）
- 现状：那行是 SwitchPreference（proxyApps），点整行都会翻转开关，同时 onPreferenceChangeListener 打开 AppManagerActivity；值一改 MainActivity 就弹重载提醒，看起来像没进页面就弹了。
- 关键核实（已查 preference 1.2.0 字节码）：`Preference.performClick()` 先调 `onClick()`（TwoStatePreference 里就是翻转开关），再调 OnPreferenceClickListener——所以在 click 监听里返回 true 拦不住翻转，不能用那招。
- 修法：新增 `ui/ProxyAppsSwitchPreference.kt`（继承 SwitchPreference），覆写 `onClick()` 只调 `onRowClick`、不翻转；开关本身点按走 Switch 的 OnCheckedChangeListener → 直接调 setChecked，不经过 onClick，所以开关照常工作。global_preferences.xml 里那行改用这个类；SettingsPreferenceFragment 里把打开 AppManagerActivity 从 change 监听移到 `onRowClick`，change 监听只保留 `DataStore.dirty = true`（开时）。
- 效果：点开关只开关（改了值，服务在运行时仍弹重载提醒）；点文字/空白只进应用选择页，不改任何设置、不弹提醒。

## 第 2 项：分应用页四个 Chip 显示不全
- 根因：ChipGroup 设了 singleLine=true、match_parent，本身不滚动；全局 Chip 样式 textStartPadding/textEndPadding 各 30dp，单个 Chip 约 114dp，四个加间隔要约 480dp，卡片里只有约 424dp，第四个「屏蔽」被裁掉。
- 修法（用户定：改小加滚动一起做）：layout_apps.xml 里四个模式 Chip 各加 `app:textStartPadding="20dp"`、`app:textEndPadding="20dp"`（单个约 94dp，四个加间隔约 400dp，放得进）；ChipGroup 外包一层 HorizontalScrollView（不显示滚动条），ChipGroup 宽度改 wrap_content，字号再变大时可滑出来兜底。只改这四个 Chip，不动全局样式。

## 第 3 项：设置名后面加单位
- 测速超时：毫秒，标题加 (ms)；空闲会话检查间隔、空闲会话超时：填时长字符串（如 15s、30s），标题加 (s)。最小空闲会话数是个数，不加（用户确认）。
- 改三处 strings.xml（values / values-zh-rCN / values-ru），单位用 SI 符号 (ms)/(s)，三语一致：url_test_timeout、anytls_idle_session_check_interval、anytls_idle_session_timeout。
